# Dart Chat add-on repository

Home Assistant add-on repository for the Dart Chat server, a private
end-to-end encrypted chat server for a closed group of friends.

## Installing

1. In Home Assistant go to **Settings > Apps** (called **Add-ons** in older
   versions) and open the store.
2. Open the menu in the top right, choose **Repositories**, and add
   `https://github.com/dartvejder/dartchat-addon`.
3. Install **Dart Chat Server** and follow its Documentation tab.
